# Pixel Garden

Idle-игра про растения: мастерская-теплица с питомцами, селекцией и книгой-альбомом.
Сервер (`server/`) считает всё сам, сайт (`site/`) только рисует.
`deploy/` — файлы для вашего сервера (на GitHub-обновление они не влияют).

- Автообновление: `bash /srv/docker/plantgame/update.sh --auto` (дальше достаточно пушить в GitHub)
- Обновить сейчас: `bash /srv/docker/plantgame/update.sh`
- Модерация: `bash /srv/docker/plantgame/garden.sh help`
- Данные: `data/garden.db` (SQLite), снимки в `data/backups/`

Папки `site/ui/` и `site/sfx/` (графика и звуки сторонних авторов) в репозиторий не входят:
загружаются на сервер один раз вручную. Без них игра работает, но панели выглядят проще.
Сцена, растения, питомцы и иконки в `site/img/` нарисованы кодом/самостоятельно и входят в репозиторий.

## Как устроен клиент (с v5.1)

Клиент не ждёт сервер. `site/sim.js` — локальная копия игровых правил (зеркало `sim`/`act` из `server/server.js`),
`site/net.js` — очередь действий. Клик сразу меняет локальное состояние (звук, частицы, монеты — без задержки),
а в фоне действия уходят пачкой на `POST /api/acts`. Ответ сервера — авторитетный снимок; не подтверждённые
действия проигрываются поверх него заново. Если связи нет, очередь хранится в localStorage и уходит позже
(у пачки есть id — сервер не выполнит её дважды). Случайное (редкость и геном нового растения или гибрида)
бросает только сервер: до ответа (доли секунды) такое растение показывается как «Росток…».

**Если меняете правила в `server/server.js` — меняйте и `site/sim.js`** (функции названы одинаково).

Управление: мышь — клик по грядке открывает меню, по значку над ней — быстрое действие; сцену можно тянуть
мышью и колесом. Клавиши (любая раскладка): W полить всё, H собрать, P посадить, 1–9 грядки, S лавка, L селекция,
A питомцы, B книга, T топ, M меню, Esc закрыть. Телефон: тот же тап, свайп вниз по шапке панели закрывает её,
кнопка «Назад» закрывает панель, а не выходит из игры.
