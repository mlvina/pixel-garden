# Pixel Garden

Idle-игра про растения: мастерская-теплица с питомцами, селекцией и книгой-альбомом.
Сервер (`server/`) считает всё сам, сайт (`site/`) только рисует.
`deploy/` — файлы для вашего сервера (на GitHub-обновление они не влияют).

- Автообновление: `bash /srv/docker/plantgame/update.sh --auto` (дальше достаточно пушить в GitHub)
- Обновить сейчас: `bash /srv/docker/plantgame/update.sh`
- Модерация: `bash /srv/docker/plantgame/garden.sh help`
- Данные: `data/garden.db` (SQLite), снимки в `data/backups/`

Папки `site/ui/` и `site/sfx/` (графика и звуки сторонних авторов) в репозиторий не входят:
загружаются на сервер один раз вручную. Без них игра работает, но панели выглядят проще.
Сцена, растения, питомцы и иконки в `site/img/` нарисованы кодом/самостоятельно и входят в репозиторий.
